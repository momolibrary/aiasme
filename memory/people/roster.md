# People Roster (人员名录)

> 核心合作者清单,用于保持人员姓名的准确性与一致性

## 团队成员

| 姓名 | 角色/职位 | 负责领域 | 别名/备注 |
|------|-----------|----------|-----------|
| -    | -         | -        | -         |

## 使用说明

1. **标准化命名**: 优先使用此表中的姓名,确保在所有文档和事件中保持一致
2. **别名记录**: 如果某人有多个常用名称(中英文、昵称等),在备注栏记录
3. **及时更新**: 有新的核心合作者加入时,及时添加到此清单

## 示例

```markdown
| 姓名   | 角色/职位      | 负责领域        | 别名/备注               |
|--------|----------------|-----------------|------------------------|
| 张三   | 产品经理       | 用户增长        | Zhang San              |
| 李四   | 技术负责人     | 后端架构        | Alex Li, 老李          |
| 王五   | 设计师         | UI/UX设计       | -                      |
```
