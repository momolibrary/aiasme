# AI Context Memory (工作上下文记忆库)

基于 Claude Code 的个人工作上下文同步系统。核心目标是**拉齐人与 AI 的上下文**，通过结构化的 Markdown 文件管理工作文档、事件、人员关系及创意交付，支持全文检索与智能关联。

## 核心理念

- **上下文同步**: 记录你阅读的文档、经历的事件，让 AI "知道"你已知的信息，减少重复背景介绍。
- **链接优先**: 针对工作文档，重点记录**原始链接 (URL)** 与核心摘要，作为 AI 获取外部信息的索引。
- **实体准确性**: 维护专门的**人员名单库**，确保核心合作者的名字准确无误，方便检索与关联。
- **闭环管理**: 从 **Idea** 诞生到最终 **交付物 (Deliverables)** 的完整生命周期记录。

## 功能特性

- **📄 文档追踪 (Docs)**: 记录阅读过的 PRD、技术方案、会议纪要的链接及关键摘要。
- **�️ 日历日志 (Calendar)**: 手动记录的每日工作流水，以日期命名，作为最原始的时间轴记录。
- **�📅 事件日志 (Events)**: 结构化记录会议、沟通、决策，包含**时间 (Date)**、**参与人 (People)**。
- **👥 人员名录 (People)**: 核心合作者档案，包含姓名、角色、别名，辅助 AI 识别与纠错。
- **💡 创意与交付 (Ideas & Deliverables)**: 灵感记录与最终产出的文件夹管理，支持从想法到落地的追踪。
- **🔍 全文检索**: 快速查找历史上下文，支持按人名、时间、关键词搜索。

│  ├─ docs/                    # 工作文档记录 (文件名建议: YYYY-MM-文档主题.md)

│  ├─ people/                  # 人员名单库
│  │  ├─ roster.md             # 核心人员清单 (姓名, 职位, 负责领域)
│  │  └─ profiles/             # (可选) 重要人物的详细画像
│  ├─ ideas/                   # 想法与灵感
│  └─ deliverables/            # 交付物管理 (按项目或Idea分类的文件夹)

│  ├─ update_index.py          # 索引更新脚本

## 快速开始

### 1. 初始化

确保 `.claude/skills/memo/memory` 下的目录结构已创建。

### 2. 在 Claude 对话中使用

#### �️ 日常记录 (Calendar)
你可以在 `memory/calendar/` 目录下手动创建以日期命名的文件（如 `2024-05-20.md`），记录当天的流水账。AI 会自动索引这些内容。

#### �📝 记录工作文档 (重点：链接)
```text
@skill memo 记录文档「Q3 营销活动方案」
链接：https://wiki.company.com/pages/view...
摘要：主要涉及双十一期间的流量投放策略，预算 50w。
涉及人员：@张三 @李四
```

#### 📅 记录工作事件 (重点：人员与时间)
```text
@skill memo 记录事件「后端架构评审」
时间：2024-05-20 14:00
参与人：王五, 赵六
结论：确认使用 gRPC 替代 HTTP 接口。
```

#### 👥 管理人员库
```text
@skill memo 新增人员「Alex」
职位：前端负责人
备注：负责中台业务，英文名 Alex，中文名王小明。
```

#### 💡 记录 Idea 与交付
```text
@skill memo 新增想法「自动化周报生成器」
...
@skill memo 归档交付物 到「自动化周报生成器/v1.0脚本」
```

### 3. 查找与回顾

```text
# 查找特定文档链接
@skill memo 查找「营销活动」的文档链接

# 回顾某人的相关事项
@skill memo 查询「王五」最近参与的会议

# 检索交付物
@skill memo 查找「周报生成器」相关的交付代码
```

## 最佳实践

1.  **人员一致性**: 在 `memory/people/roster.md` 中维护一份标准名单。AI 在记录事件时，应优先匹配库中已有的标准姓名，避免出现 "Mike" 和 "迈克" 指代同一人的情况。
2.  **链接为王**: 记录文档时，务必包含原始 URL。当你在对话中问 "总结一下那个文档" 时，AI 可以利用这个链接去尝试获取内容（如果具备联网能力）或提示你去查看。
3.  **时间戳**: 事件记录建议在文件名或 Frontmatter 中包含 `YYYY-MM-DD`，方便按时间轴回顾。
4.  **定期同步**: 每天结束工作时，花 5 分钟将当天的重要上下文同步到记忆库，保持 AI 的认知与你同步。
